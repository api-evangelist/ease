# Ease

> Ease (legally Enrollease, Inc., San Francisco) is a United States benefits administration and HR platform sold through insurance brokers to employers of roughly 2-250 employees. It was acquired by Employee Navigator in April 2023 and is now in announced end-of-life: no new companies can be added from 2027-01-01, and the platform goes read-only on 2027-07-01. Ease publishes NO public developer portal, NO benefits API reference and NO OpenAPI for its product. It does publish two real, anonymous, machine-readable read surfaces - the WordPress content API behind www.ease.com (including the full Marketplace partner directory) and the Atlassian Statuspage v2 API on status.ease.com - both captured here.

Generated by API Evangelist on 2026-07-25. Ease does not publish an llms.txt; this file is generated from the ease record in the API Evangelist network and from live probes of every Ease host on that date.

## What Ease actually exposes

- [Ease Content & Marketplace API](https://www.ease.com/wp-json/): Public, anonymous WordPress REST API. Blog posts, pages, media, events, testimonials, and the Ease Marketplace partner directory (110 partners, 16 partner types, 23 benefit types). Read-only without credentials; write routes return 401.
- [Ease Status API](https://status.ease.com/api): Public, anonymous Atlassian Statuspage v2 API. Platform status, three components (Web Application, API, Support), incidents with dated updates, scheduled maintenance. Webhook and RSS/Atom subscriptions available.
- [EaseConnect and EaseConnect+](https://www.ease.com/product/platform/marketplace/connections/): The real integration surface, and it is NOT public. EaseConnect is self-service mapping of ANSI X12 EDI 834 enrollment files to carriers inside the customer application; EaseConnect+ is a privately negotiated direct carrier data connection. The Principal EaseConnect+ integration includes an Evidence of Insurability API and a Member Benefits API that Ease has never documented publicly.
- [Partner portal](https://www.ease.com/partners/join-us/): Login-gated. Data leaves by scheduled report or SFTP.

## What Ease does NOT expose

- No developer portal. developer.ease.com, developers.ease.com, api.ease.com and docs.ease.com all resolve through wildcard DNS to the Ease application sign-in page; ease.com/developers, /api, /developer and /integrations return 404.
- No OpenAPI, Swagger, GraphQL, gRPC or AsyncAPI published by Ease.
- No OAuth, no OpenID Connect discovery, no API keys, no self-serve signup for any API.
- No SDKs, no CLI, no GitHub organization, no public Postman collection, no MCP server.
- No first-party /.well-known/ document on any Ease host.
- No ACORD, AL3, NGDS or IVANS surface - Ease is group benefits (X12 834), not P&C.

## Operating guidance

- [API conventions](https://raw.githubusercontent.com/api-evangelist/ease/refs/heads/main/conventions/ease-conventions.yml): Pagination (page/per_page, X-WP-Total, Link rel=next), sparse fields (_fields), expansion (_embed), envelope (_envelope), filtering, CORS. No idempotency, no rate-limit signalling, no request-id header.
- [Error catalog](https://raw.githubusercontent.com/api-evangelist/ease/refs/heads/main/errors/ease-problem-types.yml): The WordPress error envelope {code, message, data.status}. Not RFC 9457. Seven codes captured live.
- [Authentication](https://raw.githubusercontent.com/api-evangelist/ease/refs/heads/main/authentication/ease-authentication.yml): Anonymous for everything published; WordPress Application Passwords guard the administrative routes that are out of scope.
- [Lifecycle](https://raw.githubusercontent.com/api-evangelist/ease/refs/heads/main/lifecycle/ease-lifecycle.yml): The 2027 platform sunset, versioning, status page, incident history.
- [Data model](https://raw.githubusercontent.com/api-evangelist/ease/refs/heads/main/data-model/ease-data-model.yml): Two disjoint entity graphs - the Marketplace content graph and the Statuspage graph.
- [Webhooks](https://raw.githubusercontent.com/api-evangelist/ease/refs/heads/main/asyncapi/ease-status-webhooks.yml): Anonymous status-incident webhook subscription. The only push surface Ease has.
- [Conformance](https://raw.githubusercontent.com/api-evangelist/ease/refs/heads/main/conformance/ease-conformance.yml): Standards and compliance posture - HIPAA, SOC 2 Type II, HITRUST CSF, plus Employee Navigator's NIST, GDPR, CCPA and 23 NYCRR 500 audits.
- [Agent skills](https://raw.githubusercontent.com/api-evangelist/ease/refs/heads/main/skills/_index.yml): Three packaged skills - Marketplace partner discovery, status monitoring, content research.
- [Candidate MCP tools](https://raw.githubusercontent.com/api-evangelist/ease/refs/heads/main/mcp/ease-mcp.yml): Proposal only. Ease operates no MCP server.
